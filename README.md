# ScatterMemory 书房 · 交互验证版

本版本验证固定视角书房、书架选书、换书动画、读书笔记和留声机播放的使用体验。场景为分层 HTML/CSS/SVG；取放书采用带封面、背面、书脊和纸页厚度的 CSS 3D 书体，沿透视空间路径旋转移动。人生之书直接复用原版皮革封面、魔眼、SM 扉页和翻页算法。35 本藏书均配有独立设计的 SVG 主题封面，采用复古布纹和烫金线描风格；不是出版社封面扫描件。人生之书与阅读手记共用 page-turn.js 的 12 段弯曲翻页算法。

## 直接预览 / GitHub Pages

本文件夹完全独立，不请求数据库、统计接口、外部字体或脚本。可以直接双击 index.html；也可在本目录运行 `python -m http.server 4173` 后访问 http://localhost:4173 。

上传到 GitHub Pages 时，将本目录的全部文件及 covers、original-book 子目录完整放在仓库根目录，确保 index.html 直接在根目录；在仓库 Settings → Pages 选择相应分支及 /(root) 即可。也可以保留此目录作为现有网站的子目录。全部资源使用相对路径，兼容用户名站点和项目站点。

无需安装 Node、构建或购买服务器。原网站的访客统计依赖后端，本独立验证版没有接入该接口，也没有模拟访客人数。

## 体验路径

1. 鼠标经过书架上的书，书脊高亮；点击一本书，当前藏书先转至书脊朝外，再直线插回原位。选中的书保持书脊朝外抽出，离开书架后才转向桌面。动画书脊显示书名。
2. 点击桌上的人生之书，先进入原版书封，再点击魔眼开书；书房保留为背景。目录包含生活记录、视频分享、随心杂记，音乐统一放在留声机。点击其他藏书则打开阅读笔记、读后感、留下的问题，内容留待补充。
3. 点击留声机机身，打开音乐面板。选择本机 MP3 后点击播放。
4. 关闭面板，点击唱针可直接暂停 / 继续；换书和阅读不打断音乐。
5. 点击“放到书桌左侧”会先完成合书，再将人生之书平移到桌面左侧，只露出一部分书封；悬停高亮，点击移回中央。换成其他藏书时，人生之书也会留在左侧。台灯和桌下收纳格已移除。手机可以点击“浏览书架”放大选书。

支持键盘 Tab、Enter、Escape；阅读时左右方向键翻页。按当前设计要求，动效固定开启，不显示开关。交互状态只保留在当前页面，刷新恢复初始书籍。

## 随心杂记：公开阅读、本地编辑

人生之书的“随心杂记”现已直接展示正式日记，沿用书本的弯曲翻页。支持纯文字、纯图片与图文记录，每条最多 16 张图片；照片以白边相片叠放，点击后可放大、左右滑动或使用方向键切换。日期显示在记录右下角，长文自动续页。

访客页面没有编辑、上传、保存或删除日记的接口。旧的 diary-preview.html 链接也只会跳转到只读页面，网址加 mode=edit 不会开启编辑权限。

请使用单独提供的 **scattermemory-owner-editor.zip** 本地工作台写作，自动保存草稿并导出 diary-content.js。把导出的文件替换到本目录并通过自己的仓库重新发布，即可更新公开日记。详细步骤在编辑器包里的 README.md。只上传网站包，不要上传编辑器包或私人备份。正式 diary-content.js 初始为空，没有将排版示例当成个人日记发布。

## 加入自己的笔记（推荐，不用写代码）

1. 解压单独提供的 **scattermemory-owner-editor.zip**，打开其中的 **index.html**，点击“读书笔记”。公开网站包不包含编辑器。
2. 选择书名，填写“阅读笔记 / 读后感 / 留下的问题”。可随时切换书籍继续写，草稿自动保存在当前浏览器。
3. 点击 **下载 notes.js · 用于发布**，获得包含全部书籍笔记的文件。
4. 在 GitHub 仓库中找到书房 index.html 所在目录，上传下载的 notes.js，替换原同名文件并提交。
5. 等待 GitHub Pages 部署完成后刷新网站，即可看到新的笔记。

只在编辑页输入不会更新线上网站；访客也无法通过这个编辑页修改你的仓库。编辑页是本地写作工具，不是有管理员登录的在线后台。当前 Sites 预览需要重新发布才能同步笔记；也可以把导出的 notes.js 交给助手更新预览。

请定期点击“备份为 JSON”。换电脑或换浏览器时，用“导入 JSON 备份”继续编辑。浏览器数据被清理后，本机草稿可能丢失；GitHub 中已经发布的 notes.js 不受影响。

### 换行与分页

笔记按纯文本显示，支持中文、英文、换行；HTML 不会执行，Markdown 标记暂不转成富文本。长文根据当前书页尺寸自动分页，不丢失内容。单独一行 `---` 可手动换页，例如：

```text
这一页写我读到的一个观点。

这一段写自己的理解。
---
下一页写生活中的例子。
```

### 直接编辑文件（可选）

notes.js 的格式如下。book-1 对应《失控》，其他书的 ID 在 books.js 中按书架清单依次编号。

```js
window.STUDY_NOTES = {
  "book-1": {
    "reading": "我的阅读笔记。\n第二段。",
    "reflection": "我的读后感。",
    "questions": "接下来想继续探索的问题。"
  }
};
```

使用编辑页可自动处理引号、换行等字符，避免手动修改 JavaScript 的格式错误。不要同时在 books.js 中另外追加笔记。

## 封面与书本厚度

打开 **covers.html** 浏览全部 35 张封面，点击可放大。独立 SVG 文件在 covers/book-1.svg 至 covers/book-35.svg 中，放大清晰、无需外部资源。每本书的图案都按主题单独绘制。

books.js 中的 thickness 数组控制视觉装订厚度，桌面参考尺寸下为 12–30px，随屏幕按比例调整。轻薄读物较薄，史学、政治经济类较厚。这是视觉设计值，不对应特定出版版本的实际页数；也不随笔记字数变化。

## 加入正式音乐

在本目录新建 media 文件夹，将自己的 MP3 放入其中，修改 books.js 末尾：

```js
window.STUDY_TRACKS = [
  { title: '你的曲名', src: './media/my-song.mp3' }
];
```

然后重新上传更新文件。页面内选择的本地 MP3 只在该浏览器当前页面中播放，不上传，刷新后需要重新选择。验证使用的合成测试音没有包含在发布文件中。

## 文件入口

- diary.html / diary-reader.js：独立的只读日记页面。
- diary-core.js / diary-pages.css：人生之书和独立阅读页共用的排版、分页与照片查看器。
- diary-content.js：正式发布的日记数据，由本地编辑器导出。
- diary-preview.html：兼容旧预览链接，跳转到只读页面。
- index.html：书房。
- covers.html：35 本私人手记封面集。
- notes.js：发布给访客的笔记内容，初始为空。
- books.js：35 本藏书目录、视觉厚度、正式音乐清单。
- page-turn.js：人生之书和所有手记共用的翻页实现。

音乐区尚未配置正式作品；正式读书笔记仍为空，测试音频不包含在发布文件中。正式随心杂记初始为空，待你补充内容。
